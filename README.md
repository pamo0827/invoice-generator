# 請求書ジェネレーター

[https://pamo0827.github.io/invoice-generator/](https://pamo0827.github.io/invoice-generator/)

ブラウザだけで請求書を作成できる静的ページです。
左半分が入力フォーム、右半分が A4 サイズのライブプレビューになっています。

## 特徴

- **入力内容はサーバーに送信されません。開発者は一切保存・収集しません。** すべての処理はあなたのブラウザ内で完結します（入力の一時保存もブラウザ内のみ）。コードにも個人情報は含まれません。
- 依存ライブラリ・ビルド不要。`index.html` を開くだけで動きます。
- 「PDFで保存／印刷」ボタンからブラウザの印刷機能で PDF を出力できます（日本語フォントもそのまま出力されます）。

## 使い方

1. 左のフォームに請求情報・請求先・請求元・振込先・作業明細・金額を入力。
2. 右側のプレビューが即座に更新されます。
3. 「PDFで保存／印刷」を押し、送信先を **「PDFに保存」** にして出力。
   - 余白を **「なし」**、用紙サイズを **A4** に設定してください（プレビューと同じ見た目で出力されます）。
   - ヘッダーの帯やテーブルなどの背景色は自動的に印刷されます。
   - 保存ファイル名は `請求書_請求先_YYYYMMDD` が初期値として提案されます。

### 作業明細の詳細

詳細欄は `・`（中黒）で区切ると、箇条書きとして折り返し表示されます。

```
詳細A・詳細B・詳細C
```
