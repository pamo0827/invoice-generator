# 請求書ジェネレーター

ブラウザだけで請求書を作成できる静的ページです。
左半分が入力フォーム、右半分が A4 サイズのライブプレビューになっています。

## 特徴

- **個人情報をコードに含めません。** 入力した内容はあなたのブラウザの `localStorage` にのみ保存され、リポジトリには一切含まれません。
- 依存ライブラリ・ビルド不要。`index.html` を開くだけで動きます。
- 「PDFで保存／印刷」ボタンからブラウザの印刷機能で PDF を出力できます（日本語フォントもそのまま出力されます）。

## 使い方

1. `index.html` をブラウザで開く。
2. 左のフォームに請求情報・請求先・請求元・振込先・作業明細・金額を入力。
3. 右側のプレビューが即座に更新されます。
4. 「PDFで保存／印刷」を押し、送信先を **「PDFに保存」** にして出力。
   - 余白は「なし」、用紙サイズ A4、背景グラフィックを有効にするときれいに出ます。

### 作業明細の詳細

詳細欄は `・`（中黒）で区切ると、箇条書きとして折り返し表示されます。

```
詳細A・詳細B・詳細C
```

## 公開（GitHub Pages）

このリポジトリを GitHub に push し、Settings → Pages で公開ブランチを指定すると、
そのまま Web 上で利用できる請求書ジェネレーターになります。
